# Figure provenance and interpretation

The current paper contains five numbered figures. A graphical abstract is retained only as a separate optional asset.

| Figure | Source file | Status |
|---|---|---|
| 1 Energy/LLM overview | energy_llm_overview.pdf | Graphical map of model, tools, energy applications and security; not a validated architecture |
| 2 Coding framework | taxonomy_tree.pdf | Proposed independent coding dimensions, not experimental evidence |
| 3 Trust boundaries | trust_boundary_architecture.pdf | Synthesized information and release paths; composed efficacy is not established |
| 4 Census flow | census_flow.pdf | Historical collection counts; AI coding is not validated eligibility |
| 5 Paired evaluation | paired_evaluation_design.pdf | Proposed four-condition comparison; no new measurements |
| Graphical abstract | graphical_abstract.pdf / .png / .tiff | Current access-authority-evidence synthesis |
| Optional census chart | evidence_census.pdf / .png | Archived primary-purpose counts; not field prevalence |

Figures are programmatically drawn. The current tools/build_publication_figures.py regenerates
the graphical abstract, census flow, optional census chart, energy/LLM overview, coding diagram, trust-boundary diagram and paired design
from the current synthesis and frozen CSV. figure_palette.py defines the shared navy, blue, teal, rust, ochre and slate colors. Existing vector source figures are supplied for compilation.

The supplementary worked_evaluation_example.md uses explicitly invented numbers to illustrate
denominator accounting. Those numbers are excluded from S1-S5 and the numerical claim audit.
An earlier unused outcome-flow image is not part of the current paper or submission source.
